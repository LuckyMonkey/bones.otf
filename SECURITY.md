# Security policy

## Supported versions

The `main` branch is the supported development line. Published font files are
static artifacts and do not execute code.

## Reporting a problem

Please do not disclose a security issue in a public issue. Email the repository
maintainer through the address listed in the GitHub profile for
[`LuckyMonkey/bones.otf`](https://github.com/LuckyMonkey/bones.otf), including:

- the affected file or release;
- a minimal reproduction;
- the impact you observed; and
- whether the issue affects the build, the web demo, or downstream consumers.

The demo is static JavaScript. Reports about accessibility, unsafe HTML handling,
font parser behavior, or supply-chain changes are welcome and will be triaged as
security issues when appropriate. 🛡️
