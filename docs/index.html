BONES.OTF / 0.1.0

Anatomy, with a glyph.

A semantic Unicode-compatible symbol system for bones, organs, and tissues. The object is canonical; the glyph is only one rendering.

Not Wingdings. Ordinary letters stay ordinary. Write :femur:; the text remains meaningful without this font.
